# 10.1mybatis加载方式

## 1、懒惰加载

### Emp实体类

增加一个私有属性和相应的getset,tostring

```
private Dept dept;
```

### mybatis-config.xml配置文件

新增lazyloadingenable

```
	<settings>
		<setting name="logImpl" value="STDOUT_LOGGING"/>
		<setting name="lazyLoadingEnabled" value="true"/>
	</settings>

```

EmpMapper.xml

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper
  PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
  "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.orcal.dao.EmpMapper">

	<resultMap type="Emp" id="empMap">
		<association property="dept" column="deptno" javaType="Dept" select="com.orcal.dao.DeptMapper.selectById">
		</association>
	</resultMap>
	
	<select id="selectById" resultMap="empMap">
		select * from emp where empno=#{id}
	</select>

	<select id="selectAll" resultType="Emp">
		select * from emp
	</select>

	<delete id="delete">
		delete from emp where empno = #{id}
	</delete>
	
	<insert id="add" parameterType="Emp">
		insert into emp
		values(#{empno},#{ename},#{job},#{mgr},#{hiredate},#{sal},#{comm},#{deptno})
	</insert>
	<update id="update" parameterType="Emp">
		update emp set
		ename=#{ename},job=#{job},mgr=#{mgr},hiredate=#{hiredate}
		,sal=#{sal},comm=#{comm},deptno=#{deptno}
		where empno=#{empno}
	</update>
</mapper>
```

### EmpTest测试单元

```java
	@Test

			EmpMapper empMapper=session.getMapper(EmpMapper.class);

		}

```

## 2、注释加载

### mybatis-config.xml配置文件

添写

```
<settings>
	<setting name="logImpl" value="STDOUT_LOGGING"/>
	<setting name="lazyLoadingEnabled" value="true"/>
</settings>
```

### EmpMapper接口

使用@one注解

```
	@Select("select * from emp where empno = #{empno}")
	@Results(id="empMap",value={
			@Result(property="dept",column="deptno",javaType=Dept.class,one=@One(select="com.orcal.dao.DeptMapper.selectById"))
	})
	public Emp selectById(int empno);

	@Select("select * from emp")
	@ResultMap("empMap")
	public List<Emp> selectAll();
```
