# 10.2多条件查询

## EmpMapper接口

新增方法

```
public List<Emp> search(Emp emp);
```

## EmpMapper.xml

新增多条件查询语句

```
	<select id="search" resultType="Emp">
		select * from emp
		<where>
			<if test="ename != null">
				ename like concat('%',#{ename},'%')
			</if>
			<if test="sal > 0">
				and sal >= #{sal}
			</if>
			<if test="dept.deptno > 0">
				and deptno = #{dept.deptno}
			</if>
		</where>
	</select>
```
